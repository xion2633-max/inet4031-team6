# Week 3: Container Orchestration with k3d

Week 3 is Sprint 2 Kickoff (synchronous). You will move the application from Docker
Compose to a k3d Kubernetes cluster running inside your team container, using kompose
to translate the Compose file and fixing two known issues in its output.

**Files you will create:**
- `manifests/` - Kubernetes Deployment, Service, and Secret YAML for all three tiers

Kubernetes manifests live in a top-level `manifests/` directory, not here. This
directory exists to satisfy the Week 1 `mkdir -p` step and holds no content of its
own until Week 3.

See the full lab directions for complete steps.
