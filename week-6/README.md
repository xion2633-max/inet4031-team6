# Week 6: GitHub Actions and CI/CD

Week 6 is Sprint 3 Async (due before Sprint 3 Review). You will build a CI pipeline
that builds and pushes your Flask Docker image on every pull request, plus a
scheduled maintenance workflow, and enforce branch protection requiring CI to pass.

**Files you will create:**
- `.github/workflows/ci.yml` - Docker build/push pipeline
- `.github/workflows/` - scheduled maintenance workflow

Workflow files live in `.github/workflows/`, not here. This directory exists to
satisfy the Week 1 `mkdir -p` step and holds no content of its own until Week 6.

See the full lab directions for complete steps.
