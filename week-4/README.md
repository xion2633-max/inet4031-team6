# Week 4: Infrastructure as Code with OpenTofu

Week 4 is Sprint 2 Async (due before Sprint 2 Review). You will manage your
Kubernetes infrastructure declaratively using OpenTofu, targeting your k3d cluster
through the Kubernetes provider with a local backend.

**Files you will create:**
- `infrastructure/` - OpenTofu HCL configuration (local backend, Kubernetes provider)

OpenTofu files live in a top-level `infrastructure/` directory, not here. This
directory exists to satisfy the Week 1 `mkdir -p` step and holds no content of its
own until Week 4.

See the full lab directions for complete steps.
